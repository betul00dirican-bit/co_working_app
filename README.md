# Co-Working Reservation System

Flutter tabanlı ortak ofis rezervasyon sistemi.

## Özellikler

- Admin paneli
- Müşteri rezervasyonu
- Kiralayan paneli
- Alan ekleme
- Rezervasyon oluşturma
- Çakışma kontrolü
- Ödeme yöntemi seçimi
- Alan filtreleme
- Aktif/Pasif alan yönetimi

## Kullanılan Teknolojiler

- Flutter
- Dart
- SQL Server
